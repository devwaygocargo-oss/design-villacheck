# คู่มือ Merchant — Phase 1 remediation candidate

สถานะ: ฉบับร่าง Staging closure candidate วันที่ 6 พฤศจิกายน 2026 ไม่รับรอง Production หรือการส่ง OTP จริง

1. **บัญชี Merchant** สมัครและยืนยันตัวตนก่อนเข้าใช้ OTP login User เดิมสมัครเป็น Merchant ด้วย ID เดิมได้: เข้าบัญชีผู้ใช้ เลือกสมัคร Merchant กรอกข้อมูลธุรกิจ ช่องทางติดต่อ ข้อมูลบัญชีรับเงิน และยอมรับเงื่อนไขสำเร็จจึงได้รับ Merchant capability โดยข้อมูลส่วนตัวและประวัติเดิมยังอยู่ ไม่ต้องรอ Admin อนุมัติบัญชี Merchant ส่วนการตรวจเอกสารและอนุมัติที่พักยังเป็นไปตามเดิม User ที่ยังไม่สมัครเข้า Merchant Dashboard ไม่ได้ หลังสมัครใช้ session เดียวเปิดพื้นที่ User และ Merchant ได้ รหัส OTP ผูก role, purpose, account และ browser ตาม flow รหัสมีอายุ 5 นาทีและ cooldown 60 วินาที การตอบรับคำขอไม่ยืนยันว่าบัญชีมีอยู่หรือส่งรหัสแล้ว
2. **โปรโมชั่นและสิทธิ์** บัญชี Merchant ใหม่ที่ยืนยันตัวตนและเข้าเงื่อนไขได้รับ Online Verify ฟรี 3 เดือนปฏิทิน เพิ่มที่พักไม่จำกัดระหว่างช่วงใช้ฟรี วันเริ่มและสิ้นสุดอ่านจากระบบ สิทธิ์และ Basic Grant เดิมไม่ถูกเปลี่ยนย้อนหลัง หน้า Coming Soon ไม่เปิดซื้อแพ็กเกจ และไม่มีการเรียกเก็บอัตโนมัติ
3. **ลงทะเบียนที่พัก** กรอกชื่อ TH/EN และเลือกจังหวัดจากรายการ 77 จังหวัด แนบเอกสารที่จำเป็นก่อนส่ง ระบบตรวจชนิด/ขนาดไฟล์และตรวจซ้ำที่เซิร์ฟเวอร์ ไฟล์ที่นามสกุลไม่ตรงกับเนื้อหาถูกปฏิเสธ ไม่ส่งซ้ำโดยเดาเองเมื่อระบบแจ้ง conflict
4. **ฉบับร่างส่วนตัว** บันทึกข้อมูลชื่อ/ติดต่อ/ธนาคาร/ชื่อบัญชี/เลขบัญชีได้ โหลดฉบับร่างกลับมาใช้ได้ Draft มี revision หากมีการแก้ไขพร้อมกัน ระบบปฏิเสธการเขียนทับข้อมูลใหม่และให้โหลดล่าสุด ไม่มีการบันทึกใน browser localStorage เพื่อใช้แทน private server draft
5. **สื่อระหว่างรอตรวจ** เจ้าของที่มีสิทธิ์และ Admin อ่านไฟล์ pending ผ่าน authenticated endpoint ได้ บุคคลอื่นและ Guest อ่านไม่ได้ การเลือกรูปปกใหม่ทำให้ต้องตรวจรูปปกใหม่ สื่อไม่ผ่านการตรวจไม่กลายเป็นสื่อสาธารณะด้วยการบันทึกข้อมูล
6. **จัดการรีวิว** เปิดรายละเอียดที่พักของตนเองเพื่ออ่านและตอบรีวิวที่เผยแพร่แล้ว เจ้าของไม่เห็นแบบฟอร์มเขียนรีวิวตนเอง และเขียนแทน User ไม่ได้ ทุกแพ็กเกจใช้ moderation เดียวกัน การตอบรีวิวไม่ทำให้ pending/rejected เผยแพร่
